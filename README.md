# One-line gadget roast

This is a small, self-contained program that writes one short text for make.fun's bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`: a single original line roasting a gadget or app used every day. The entry is the 83-character roast below, and `main.py` writes exactly those bytes, with no trailing newline, into the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `OUTPUT_DIR`, then `/output`), creating the folder if needed and printing the character count to stderr.
